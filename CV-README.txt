PERSONNALISER TON PORTFOLIO

1. Ouvre index.html dans un éditeur de texte ou Visual Studio Code.
2. Remplace le lien mailto:TON.EMAIL@EXEMPLE.FR par ton adresse professionnelle.
3. Ajoute ton CV au format PDF dans ce dossier et nomme-le CV.pdf.
4. Vérifie les dates et les intitulés de formation/expériences.
5. Dans la section projets, garde le statut « À réaliser / compléter » jusqu'à ce que tu aies réellement fait le projet.
6. Retire ou ajuste les compétences que tu n'as pas encore étudiées.
7. Ouvre index.html dans ton navigateur pour prévisualiser le site.

Le site est statique : il fonctionne sans serveur. Google Fonts nécessite une connexion pour charger la police, mais le site reste utilisable sans elle.
Pour le publier gratuitement, tu peux utiliser GitHub Pages : https://pages.github.com/
